# 接口层与前端设计

- 状态：现行（已确认）
- 日期：2026-10-24
- 上位规格：`2026-10-24-collection-agent-design.md`（业务约定以上位规格为准）
- 范围：后端接口层（含运营回答的大模型流式生成）、前端对话台、案件与审计台、运营管理台。

## 1. 仓库与运行方式

- 后端仓库 `AICustomerService`：新增 `backend/api/`（FastAPI）。进程内只有一个主控 Agent 实例，它持有一个运营子 Agent；进行中的催收子 Agent 按会话存在于进程内存。所有对话与写操作请求串行处理（全局锁），因为 SQLite 为单连接。
- 前端仓库 `AICustomerService-web`：Vite + React + TypeScript + Ant Design，路由 react-router；接口类型由后端 OpenAPI 通过 `openapi-typescript` 生成。
- 开发：Vite 把 `/api` 代理到后端 `http://127.0.0.1:8000`。
- 部署：前端 `npm run build` 产出 `dist`，由 FastAPI 托管为单页应用，单端口访问；前端产物目录由环境变量 `WEB_DIST` 指定，默认为后端仓库同级的 `AICustomerService-web/dist`。后端仓库提供一键启动脚本。

## 2. 运营回答的大模型流式生成

- 事实稿：运营模式下按查询或校验结果拼出的确定性回答称为事实稿。画像、欠款、报告和合规问答的事实稿由运营子 Agent 生成；发起催收的开场和结束催收的事实稿由主控生成。话术审核结论不进入事实稿流式生成。
- 交互界面中，运营回答由大模型基于事实稿逐字生成：只复述和组织事实稿，不得增加事实稿以外的数字、规则编号或结论。
- 脱敏：调用前事实稿经脱敏网关替换姓名、证件号、手机号、金额为占位符；流式返回的文本在占位符完整后才还原，再做显示脱敏后推送；每次调用写入大模型调用记录。
- 数字核对：生成结束后，回答中出现的每个数字都必须在事实稿中出现（行首的列表序号如「2.」「3、」不计）；不通过时推送替换事件，界面以事实稿整段替换已显示内容，处理轨迹中标注「数字核对未通过，已改用事实稿」。
- 兜底：大模型不可用、调用失败或超时，直接逐字推送事实稿。
- 本轮结论（`done` 事件）中的回答为界面最终显示的文本；批量测评仍输出事实稿，保证同输入同输出。
- 发给客户的坐席回复与话术审核结论不经此流程：后台完成并通过检查点一后整段推送，前端做逐字效果。

## 3. 接口

### 3.1 对话（SSE）

`POST /api/chat`，入参：`text`、`session_id`（可选）、`role`（可选：`operator / customer / agent / human_agent`）、`customer_id`（可选）、`now`（可选，模拟当前时间）。

每个 HTTP 请求带轨迹编号，格式 `TR-` 加 10 位十六进制。调用方通过请求头 `X-Trace-Id` 传入合法编号时沿用，否则服务端生成。响应头回写同一个编号。对话处理、工具调用、大模型调用和由该请求触发的后置任务使用这一个编号；`done` 事件里的轨迹编号与响应头相同。`/api` 请求在服务日志里打一行，包含方法、路径、状态码、耗时，并且每条 `cagent` 日志都带该编号。静态页面请求不写这行日志。前端每次对话新生成编号并传给 `/api/chat`，随后的建议请求沿用响应头里的编号；其余接口各自生成编号。

事件按以下顺序推送：

| 事件 | 内容 |
| --- | --- |
| `trace` | 处理轨迹的一步（步骤、名称、状态、详情、耗时），每完成一步推送一个 |
| `delta` | 回答文本片段 |
| `replace` | 数字核对未通过时，用于整段替换的事实稿 |
| `done` | 本轮完整结论（会话编号、模式、说话人、系统意图、最终回答、命中规则、意愿评分与等级、建议策略、是否转人工、移交包编号、主动结束原因（为空表示未结束）、需人工复核及原因、要点、轨迹编号、大模型用量）。用量是本轮新发生的调用合计：输入 token、输出 token、缓存命中 token。一次回复里的理解、合规和叙述都算在内，之后单独请求的追问建议不算。本轮没有大模型调用时用量为空 |
| `error` | 处理失败的原因；之后不再推送其他事件 |

角色 `human_agent` 表示人工坐席发言，仅在人工接管模式下有效。

### 3.2 其他接口

| 类别 | 接口 |
| --- | --- |
| 客户 | `GET /api/customers?q=`（编号或职业、地区模糊搜索）；`GET /api/customers/{customer_id}`（画像、逾期及优先级、意愿评分，经运营子 Agent 的工具注册表查询，字段不变） |
| 追问 | `POST /api/suggestions`（入参 `reply`、`role`、可选 `customer_id` 与 `session_id`）。按最新 AI 回复生成当前角色接下来可能说的 3 句话；大模型不可用或不足 3 条时用回复内容兜底。计入成本，并挂到传入的会话 |
| 会话 | `GET /api/sessions`（按开始时间倒序；`resumable` 为真表示未结束，且处于人工接管，或催收子 Agent 仍在本进程内存中）；`GET /api/sessions/{session_id}`（会话信息、对话记录、会话记忆、移交包、后置任务状态）；`POST /api/sessions/{session_id}/end`；`POST /api/sessions/{session_id}/handoff/finish`（入参 `conclusion`） |
| 后置任务 | `POST /api/sessions/{session_id}/postcall/retry`（入参 `name` 可选，为空时重试全部失败任务） |
| 案件 | `GET /api/cases?customer_id=&status=`；`GET /api/cases/{case_id}`（会话、产出物、待办）；`POST /api/cases/{case_id}/archive` |
| 产出物 | `GET /api/artifacts/{artifact_id}` |
| 审计 | `GET /api/audit?rule_id=&checkpoint=&customer_id=`；`GET /api/audit/export`（CSV 下载，敏感字段脱敏） |
| 成本 | `GET /api/costs?start=&end=`（按调用时间闭区间筛选，空表示不限）。汇总与按会话分组返回调用次数、输入缓存命中/未命中 token、输出 token、费用（人民币，字段 `cost_cny`）。单价为中文文档 deepseek-flash 价：每百万 token，闲时缓存命中 0.02 元、缓存未命中 1 元、输出 4 元；工作日北京时间 09:00–12:00 与 14:00–18:00 为高峰，单价翻倍；周末全天闲时。没有 token 的历史调用计入次数并标为未记录，不计入费用。未挂到会话的调用单独成组。 |
| 记忆 | `GET /api/memory/{scope}/{owner_id}`；`PUT /api/memory/{scope}/{owner_id}/{key}`（纠正）；`DELETE /api/memory/{scope}/{owner_id}/{key}`（清除）；纠正与清除写入审计 |
| 配置 | `GET /api/config`（各配置当前版本，含业务包列表）；`GET /api/config/{kind}/{key}`；`PUT /api/config/{kind}/{key}`（业务包先校验，不通过返回 422 及错误清单）；`GET /api/config/{kind}/{key}/versions`；`POST /api/config/business_pack/{key}/copy`（入参新业务包编号与名称）；`GET /api/registry`（分组 `main`、`ops`、`collection:{业务包编号}`，分开列出工具和 Skill） |
| 规则与模板 | `GET /api/rules`、`PUT /api/rules/{rule_id}`、`POST /api/rules`；`GET /api/templates`、`PUT /api/templates/{template_id}`、`POST /api/templates`。同一编号读取时优先用系统生成的覆盖行。保存不改原始导入行，也不改赛题 CSV。规则级别只能是轻微、中等、严重。校验失败返回 422 及错误清单；编号已存在时新增返回 409 |

接口返回的客户姓名、证件号、手机号均经显示脱敏。

## 4. 前端页面

左侧导航：对话台、案件与审计台、成本、运营管理台。

### 4.1 对话台

对话台按当前会话模式切换整页布局，共三套：运营、催收对话、人工接管。左侧客户栏（客户下拉、客户档案、会话列表）在三套布局里都常驻，点开未结束会话时不隐藏。三套布局读写同一份数据：当前客户、会话、对话记录、每一轮的轨迹事件与本轮结果、会话记忆、移交包、后置任务状态。切换布局不复制数据；回到同一会话时看到的仍是这份数据。页面标明当前模式。

话术审核不单独占一套布局，在运营布局中完成。

- 运营布局：客户用下拉框选择，可按编号、职业、地区或姓名搜索，清空后取消当前客户；客户卡片（画像、逾期及优先级、意愿评分与等级）；会话列表（可继续、需重新发起、已结束），点开后回到该会话；运营提问与回答；话术审核；「发起催收」「结束催收」；角色选择（运营 / 客户 / 审核话术 / 人工坐席）；可选的模拟时间。还没有 AI 回复时，输入框上方是该角色的固定示例；出现新的 AI 回复后，改为按这条回复和当前角色生成的 3 条可能接着说的话，点选填入输入框。切换角色会按同一条回复重新生成。
- 催收对话布局：同一会话的对话记录。客户发言与 AI 坐席回复按轮显示。AI 坐席话术气泡及其上方轨迹遵从上位规格 15.1。角色选择与「结束催收」仍可用。
- AI 生成的话术在气泡下方用小字显示本轮用量：输入 token、输出 token、缓存命中 token。包括运营子 Agent 的回答和 AI 坐席回复。没有大模型调用时不显示，例如离线模板和未调用模型的开场白。用量不写入话术正文。AI 坐席回复会把这三个数写入该条对话记录，重新打开会话仍显示；运营问答不落库，只在当次对话里显示。
- 人工接管布局：同一会话的对话记录与移交包。输入角色默认为人工坐席，发言写入同一对话记录。「完成处理」提交结论后回到运营布局。

### 4.2 案件与审计台

- 案件列表（按客户、状态筛选）与案件详情：会话列表及对话记录、催收报告（Markdown 渲染）、移交包、后置任务状态与重试、待办、会话记忆的查看、纠正与清除；可归档。
- 报告页 `/reports/{产出物编号}`：打开对话里「查看完整报告」链接对应的产出物，渲染其中的 Markdown。
- 审计日志标签页：按规则编号、检查点、客户筛选；导出 CSV。

### 4.3 成本

- 页面展示所选时间内的总调用次数、输入 token（缓存命中与未命中分开）、输出 token 和费用，以及每个会话的同样数字。
- 可用日期范围筛选；清空后为全部时间。
- 页面写明当前单价和高峰规则。文档里的中国法定节假日豁免未接入日历，节假日仍按星期判断。
- 没有 token 记录的调用显示为未记录，费用按 0 计。

### 4.4 运营管理台

- 业务包：列表、复制新建、主要字段表单编辑（名称、适用贷款类型、前置工具及失败策略、门禁、转人工条件、主动结束条件、话术约束、后置任务），全部字段可用 YAML 编辑；保存时展示校验错误；查看版本历史。主动结束的「累计拒绝次数」读写 `exit.max_refusals`，打开表单时显示已保存的数字；留空保存后不因拒绝主动结束。
- 评分与策略：表单编辑意愿评分权重、等级阈值、策略表。
- 合规检查点、意图映射：YAML 编辑。
- 工具注册表：表单编辑说明、超时、重试次数和是否启用，也可改 YAML。名称、类别、归属和输入输出契约由代码注册，不能增删。保存后运营子 Agent 立即使用新配置；已经打开的催收会话不变，下一通催收会话使用新配置。停用的运营工具不再出现在业务包的前置工具选项里。
- 合规规则库：可改类型、规则内容、级别和处置，也可新增。级别只能是轻微、中等、严重。保存后当前进程的合规检查立即使用新条文。各检查点启用哪些规则、关键词、时段和频次仍在「合规检查点」里配置。
- 分期模板：可改类型、最长期数、年化利率、手续费率和适用条件原文，也可新增。界面按百分比填写利率和手续费率，接口仍保存小数（7.2 表示 7.2%）。适用条件里的逾期天数和信用评分从原文解析，下一次测算读取新模板。
- 这两处都不删除记录。编辑不改写原始导入行，另存一条系统生成的覆盖行；同一编号再次保存只更新覆盖行。赛题 CSV 不改。

## 5. 错误处理

- 对话处理失败推送 `error` 事件；网络中断时界面提示并允许重发，不静默。
- 配置保存校验失败时不生效，界面逐条展示错误。
- 后置任务失败在案件详情标红，可单个或整体重试。

## 6. 测试与验收

- 后端：FastAPI TestClient 离线覆盖各接口；SSE 事件顺序（`trace` → `delta` → `done`）；数字核对不通过时推送 `replace`；大模型不可用时逐字推送事实稿；业务包校验失败返回 422。
- 前端：vitest 覆盖 SSE 解析与对话状态更新；TypeScript 类型检查与打包通过；浏览器走通合规催收、分期协商、人工接管三个场景。

## 7. 明确不做

- 管理台删除合规规则或分期模板，以及改写原始导入行和赛题 CSV。
- 登录与权限管理。
- 多进程或多实例部署。
- 在界面中运行批量测评（使用命令行脚本）。
